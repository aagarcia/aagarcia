## Lo que hago

- **Servicios backend empresariales** con .NET 9/10, Minimal APIs, Entity Framework Core y arquitectura en capas (Clean Architecture, SOLID, microservicios).
- **Bases de datos**: **Oracle PL/SQL** (20 años de experiencia, de 10g a 19c), SQL Server, PostgreSQL, MySQL y **MongoDB** (4 años), con procedimientos almacenados, triggers y optimización.
- **Automatización y arquitectura orientada a eventos en Azure**: Functions, Event Grid, Azure SQL y PostgreSQL.
- **IA aplicada**: servidores **MCP** que conectan Claude con datos empresariales (herramientas de solo lectura, seguridad y observabilidad con OpenTelemetry).
- **Integración de sistemas**: servicios REST y SOAP, webservices y migración de servicios entre plataformas.
- **Frontend y móvil**: Blazor WebAssembly, Tailwind, **Angular** (2 años), React y Flutter.
- **Formación**: docencia universitaria en programación, bases de datos y desarrollo móvil.

**Sectores donde he trabajado:** telecomunicaciones, banca, pagos con tarjeta, logística, agroindustria y educación.
